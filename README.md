# JavaScript Exercises

A collection of JavaScript exercises covering fundamental and intermediate JavaScript concepts, including functions, arrays, objects, JSON, ES6 features, modules, web storage, session storage, cookies, and more.

These exercises were created to practice JavaScript concepts through small, working examples.

## Running the Exercises

Most basic JavaScript exercises can be run directly in a browser or with Node.js, depending on the exercise.

Exercises that use browser features such as:

* DOM manipulation
* `localStorage`
* `sessionStorage`
* Cookies
* ES modules

should be opened through a local development server.

For example, using VS Code with the Live Server extension:

1. Open the repository in VS Code.
2. Open the folder containing the exercise.
3. Open its `index.html`.
4. Start Live Server.
5. Open the provided local URL in your browser.

## Repository Structure

The exact structure may vary depending on how the exercises are organized, but browser-based exercises generally contain files such as:

```text
Exercise/
├── index.html
└── script.js
```

Exercises involving modules may contain:

```text
Exercise/
├── index.html
├── app.js
├── students.js
└── grades.js
```

## Purpose

The purpose of this repository is to practice JavaScript by implementing each concept in a small, focused exercise.

The exercises progress from basic JavaScript syntax and array methods to more advanced topics such as inheritance, modules, browser storage, and cookies.
